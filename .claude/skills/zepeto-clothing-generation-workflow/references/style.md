# ZEPETO 穿戴物品的樣子：照參考照刻細節＋寫實布料

> 2026-10-14 改版。之前是「黏土玩具風」（形狀簡化、霧面單色、不做皺摺）。做新娘禮服時，使用者說黏土風不適用，看過三種質感並排比較（ZEPETO 卡通著色／混合／寫實布料）後選了**寫實布料**，並決定**所有衣服都改用這個做法**。
> 已定案的舊衣服（新郎米色三件式、攝影師黑色便服、新娘 v1 黏土風禮服）還是黏土風，之後要照這份重做（重做前先問使用者時機）。

## 研究依據（ZEPETO 官方 Studio Guide，2026-10-14 查）

- 官方衣服＝低面數形狀＋256～512 的貼圖＋卡通著色（Toon Shader，可加法線、陰影門檻、遮罩貼圖）。洋裝上限 1 萬三角面。
- **影響輪廓的摺子、荷葉邊用模型做**；表面小細節（縫線、花紋）畫在貼圖。
- 袖口、裙襬加一層內裡看起來才有厚度；裙子內側要封起來或有厚度（引擎預設背面不畫，動起來會看到破洞）。
- 創作者常用 Marvelous Designer 做出自然垂墜，再固定成模型。
- 我們不是要上架 ZEPETO，是在 Blender 渲影片，所以**不受面數、貼圖大小限制**；取的是「摺子做在模型上、垂墜要自然」這個方向。卡通著色試過，使用者沒選。

來源：[3D Modeling - Clothes](https://docs.zepeto.me/studio-guide/3d-modeling-clothes)、[3D Texture Optimization Guide by Category](https://docs.zepeto.me/studio-guide/3d-texture-optimization-guide-by-category)、[3D Modeling Optimization Guide by Category](https://docs.zepeto.me/studio-guide/3d-modeling-optimization-guide-by-category)

## 造型

| 項目 | 做法 |
| --- | --- |
| 輪廓 | 照參考照，不再刻意簡化成大形。尺寸照照片比例（例：蓬裙下襬寬約腰到地高度的 1.5 倍） |
| 摺、荷葉邊、層次 | **做在模型上**：放射摺、捲邊、瀑布荷葉邊、多層紗、緞帶玫瑰、燕尾垂帶、中空蝴蝶結圈（配方見 `garment_detail.py`） |
| 垂墜 | 會垂的布（外層紗、荷葉邊）：先用公式排出大摺，再用**布料模擬在靜止姿勢垂一次**定形、套用成形狀。動畫時不模擬（不會變慢、每次重長結果一樣） |
| 厚度 | 薄布 1.5～2 mm（歐根紗、緞帶）；裙子、上身另有內層或厚度，內側不會破 |
| 小配件 | 扣子、耳環、鞋帶照照片做；太小看不到的可以略放大 |
| 照片看不清的 | 自己補，在審看頁「已知問題」寫明是補的 |

## 材質（`garment_detail.fabric(name, rgb, kind)`）

| 布料 `kind` | 用在 | 樣子 |
| --- | --- | --- |
| `organza` ✔ | 歐根紗上身、外層紗、荷葉邊、蝴蝶結 | 硬挺、有亮面反光、微透 |
| `satin` ✔ | 緞帶、腰帶、布花 | 光澤、不透 |
| `tulle` ✔ | 蓬紗 | 半透明：正看較透、斜看較密，一層層疊出深淺 |
| `lining` ✔ | 襯裙 | 柔光、不透 |
| `canvas` ✔ | 帆布鞋 | 霧面 |
| `metal` ✔ | 銀飾 | 金屬 |
| `wool`、`cotton`、`knit`、`denim`、`leather`、`pearl` | 西裝、襯衫、針織、牛仔、皮鞋、扣子 | 起始值，第一次用要看近照調 |

✔＝新娘細節版禮服實測、使用者看過。

- 顏色：色相照照片；婚紗白用奶油白（約 #F7F1E8），深色西裝用深藍灰，不用純黑。
- 半透明材質在 EEVEE 用 Dithered（一層層疊才排得對）。近看薄紗會有細顆粒感（渲染雜訊），正式渲染提高取樣會比較細。
- 皮膚和頭的材質由身體端負責（2026-10-14 起身體端也拿掉了黏土風，頭改亮澤）；衣服用寫實布料。

## 授權

- 自己用配方建的：沒有授權問題。
- 不要拿 ZEPETO 官方的模板、商店服裝（NAVER Z 所有）。
- 要用外部素材（首飾模型、布料貼圖）時，規則同場景道具：CC0 直接用、CC BY 要標註、NC／ND／SA 不用、下載前先問使用者。來源清單共用 `library/props-zepeto/sources.md`。
