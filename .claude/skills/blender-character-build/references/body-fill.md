# 補皮膚（body_fill.py）

## 為什麼要補

VRoid 匯出 VRM 時會刪掉「被衣服蓋住、看不到」的皮膚。預設 T 恤＋短褲的角色，被刪的是：胸口到鎖骨、肩膀、**整片上背**、上臂（手肘以上），腰部以下大多還在（短褲底下的皮膚貼圖上畫著黑色內褲）。換成平口、露肩、無袖的服裝，或要展示便服時，這些地方會變成破洞（看起來像穿了黑色內衣）。

## 做法（run_fill 依序做）

1. `delete_dark_band()`：皮膚貼圖在衣服邊緣畫了黑色內衣帶，刪掉那圈面（下面有補丁墊著）。
2. `build_blocks()`：
   - 軀幹：15 個截面（`SECTIONS`，z／半寬／前／後）loft 成一段，截面形狀是 2.4 次方的超橢圓（略方）。
   - 胸部：兩個橢球，略往外、往上翹（`body.bust=false` 時不做）。
   - 上臂：從既有手臂 x=0.27 的**真實截面**出發，往肩膀逐步放大（`ARM_GROW`），所以接縫處形狀一模一樣。⛔ 不要用圓管，上臂截面是扁的，圓管在正面看會有一個階梯。
   - 斜方肌、鎖骨：兩根細管。
3. `remesh()`：體素重建（3 mm）＋拉普拉斯平滑 35 次，合成一塊光滑的面。
4. `trim()`：切掉 z<1.0、z>1.40、|x|>0.255 的部分（和既有皮膚重疊一段）。
5. `snap_to_skin()`：離既有皮膚 5 mm 內的頂點吸到皮膚內側 1 mm，5～22 mm 漸變 → 接縫沒有縫。
6. `finish()`：接縫附近（8～30 mm 漸變）的法線改用既有皮膚的（否則光影差 13°，看得到一條線）；權重從 `_SRC`（原始含衣服的身體）轉移；加骨架修改器。
7. `fill_material()`：複製皮膚材質，底色/陰影貼圖換成 16×16 漸層（軀幹、手臂、脖子三個實測膚色），**拿掉法線貼圖**（補丁 UV 不對應它，會出現雜訊），輪廓線關掉。

## 換角色

- 所有座標乘 `S = 頭骨高 / 1.386`（新娘的頭骨高）。身高差在 ±15% 內通常直接可用。
- 男性：`--bust no`；肩寬多半比較寬 → 檢查圖若看到肩膀內凹，把 `SECTIONS` 裡 z 1.20～1.29 的半寬加大 5～10%。
- 若 `_arm_loft` 報「x=0.27 處切不到手臂截面」：這個角色的上衣是長袖，手臂皮膚也被刪光了 → 把 `ARM_GROW` 的起點改到手腕附近仍有皮膚的位置（例 0.45），中間用放大倍率補。
- Q 版、頭身比例差很多：截面不適用，要重新量（用 `measure.py` 的 `section()` 切 `_SRC` 的 Tops 截面當參考，扣掉 5～8 mm 衣服厚度）。

## 檢查（一定要看圖）

| 檢查圖 | 看什麼 |
| --- | --- |
| 正面、斜前 | 胸口、鎖骨形狀自然；沒有黑色帶 |
| 手臂正面、背面近照 | x≈0.21～0.25 的接縫：有沒有一條線、顏色有沒有差、上緣有沒有缺口 |
| 腰側近照 | z≈1.0～1.05 背面接縫 |
| **轉角色 180° 用正面燈光**拍背面 | 上背有沒有凸起、肩胛有沒有怪球 |

⚠️ 從背後打燈拍會看到 MToon 的硬邊亮塊，那是燈光不是破圖；判斷背面一律轉角色。

已知小瑕疵（新娘專案也有）：腰後 z≈1.05 在特定角度看得到一條很淡的線；肩膀後方被背光打到時有零星亮塊。
