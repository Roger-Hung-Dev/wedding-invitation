# 道具與鏡頭經驗值

## 道具工具（scene_lib.py）

| 函式 | 做什麼 |
| --- | --- |
| `clear_props()` | 清掉 SceneProps 集合裡的東西（每個情境 build 開頭呼叫） |
| `mat(name, 受光色, 陰影色, alpha, emit)` | MToon 材質；emit＝自發光 |
| `image_mat(name, png)` | 圖片貼圖（報紙、海報），自發光 0.95 |
| `box / cyl / ball(bm, …)` | 往同一個 bmesh 加方塊、圓柱（可上下不同半徑）、球；`mi` 指定材質槽 |
| `solid(name, bm, [材質…])` | bmesh → 物件，放進 SceneProps |
| `text_obj(name, 文字, 大小, 位置, 旋轉, 材質, 字型)` | 3D 文字（霓虹招牌） |
| `seat_legs(P, hip_z)` | 坐姿雙腿 |
| `arm_pose(P, side, (ua_y, ua_x, ua_z, fa_x, fa_z))` | 參數化手臂（方便在姿勢間內插） |
| `keys_interp(keys, t)` | 關鍵格向量平滑內插 |
| `set_world(bg, floor)` | 背景與地板 |
| `render_scene(...)` | 物理＋渲染迴圈（run_scene 會呼叫） |

## 鏡頭配方

| 情境 | 位置 → 看哪裡 | 焦距 |
| --- | --- | --- |
| 全身、站姿 | (0.5, −4.2, 1.5) → (0, 0.2, 1.1) | 32～36 |
| 坐姿、手上有東西 | 斜前偏高 (−1.6, −1.4, 1.5) → (0, −0.2, 0.75) | 40 |
| 角色＋側邊場景 | 場景那側的斜前方，讓角色佔畫面 1/3 | 34～38 |
| 繞圈 | 半徑 3.3、高 1.35，角度 −18°→+18° | 40 |
