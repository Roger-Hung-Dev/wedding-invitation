# 轉場（Transition）

轉場＝**這一鏡怎麼接到下一鏡**。寫在分鏡卡的「列-轉場」。一鏡之內的動作見 [[fx-camera-motion]]。

## 共通規則

1. **轉場寫在前一鏡**：S1-05 的轉場欄寫的是「S1-05 → S1-06」怎麼接。最後一鏡寫的是接到片尾的方式。
2. **時長必須寫出來**（`溶接 0.8s`，不是「溶接」）。解析器只認下表寫法。
3. 全形括號 `（…）` 只給人看，例 `硬切（對齊鼓點）`。
4. 時長的單位是秒，寫 `s`。
5. **切點＝時間碼的交界**（S1-05 的終點＝S1-06 的起點）。轉場是以切點為基準展開的，不會改變時間碼。

### 兩種轉場型態

| 型態 | 包含 | 時間窗 | 實作 |
| --- | --- | --- | --- |
| **交疊型** | 溶接、推移 | 以切點為中心，前後各 `duration/2` | 兩鏡**同時算圖**再合成；交疊期間兩鏡的運鏡都還在跑（進度 p 會略小於 0 或大於 1） |
| **覆蓋型** | 黑場、閃白 | 切點前一段改本鏡尾、切點後一段改下一鏡頭 | 疊在單鏡畫面上 |

⚠️ 交疊型的 `duration/2` 不能超過相鄰兩鏡任一鏡的長度一半，否則三鏡同時出現（`build_storyboard.py` 會擋）。

## 條目

### `cut` 硬切

| 項目 | 內容 |
| --- | --- |
| 狀態 | 已實作 |
| 分鏡寫法 | `硬切` |
| 圖示 | `scissors` |
| JSON | `{"type":"cut"}` |
| 使用時機 | 快節奏段落（2～3 秒一鏡）、對齊鼓點、情緒轉折 |

⚠️ 分鏡稿常寫「對齊鼓點」，但**產生器沒有拍點資料**，切點一律落在時間碼上。要對拍，必須把拍點時間直接寫成時間碼（見 [[storyboard-planning]] 的配樂一節）。

### `dissolve` 溶接

| 項目 | 內容 |
| --- | --- |
| 狀態 | 已實作（`overlap_render()`） |
| 分鏡寫法 | `溶接 0.8s` |
| 圖示 | `blend` |
| JSON | `{"type":"dissolve","duration":0.8}` |
| 演算法 | 切點前後各 `duration/2`；權重 `smoothstep((t − (切點 − d/2)) / d)`，兩鏡直接 blend |
| 慣用值 | 一般 0.8s；抒情章節 1.5s（第 3 章整章用 1.5s）；片尾內部 1.0s |
| 使用時機 | 同章節內情緒連續的鏡頭；本片 55 鏡裡 25 次是溶接 |

### `push` 推移

| 項目 | 內容 |
| --- | --- |
| 狀態 | 已實作 |
| 分鏡寫法 | `推移 → 0.6s`、`推移 ← 0.6s` |
| 圖示 | `→` 用 `chevrons-right`；`←` 用 `chevrons-left` |
| JSON | `{"type":"push","dir":"right","duration":0.6}` |
| 演算法 | 箭頭＝畫面移動方向。`→`：本鏡往右推出、下一鏡從左側推入。位移 `smoothstep` × 畫面寬，取整數像素 |
| 使用時機 | 分割畫面（B 版型）的進出，強化「一格一格翻過去」的感覺 |

⚠️ v1 分鏡稿往左的推移也用了 `chevrons-right`，看圖會誤判方向。v2 起**圖示要跟箭頭一致**。

### `flash` 閃白

| 項目 | 內容 |
| --- | --- |
| 狀態 | 已實作 |
| 分鏡寫法 | `閃白 0.08+0.22s 85%` |
| 圖示 | `zap` |
| JSON | `{"type":"flash","pre":0.08,"post":0.22,"peak":0.85}` |
| 演算法 | 切點前 `pre` 秒線性升到 `peak` 白；切點後 `post` 秒線性退回。峰值落在切點，兩鏡**不交疊**（本鏡尾刷白、下一鏡頭從白退出） |
| 使用時機 | 進副歌第一拍、高潮段的重拍；一章最多 3～4 次，用多了會廉價 |

⚠️ 峰值不要用 100%：純白在投影上會刺眼，而且壓縮後會出現色帶。

### `black` 黑場溶接（章節轉換）

| 項目 | 內容 |
| --- | --- |
| 狀態 | 已實作 |
| 分鏡寫法 | `黑場 0.5+1.5s`（可加說明 `（章節轉換）`） |
| 圖示 | `square` |
| JSON | `{"type":"black","out":0.5,"in":1.5}` |
| 演算法 | 本鏡最後 `out` 秒**線性**淡到黑；下一鏡前 `in` 秒以 **smoothstep** 從黑淡入 |
| 使用時機 | **只用在章節交界**（片頭→第 1 章、章→章、最後一章→片尾）。章內不用 |

⚠️ 下一章第一鏡通常搭配「慢拉 115→100%」，從黑場裡把場景拉出來。
⚠️ 片頭最後一張卡的轉場就是片頭接正片的黑場；最後一鏡的黑場則決定片尾的淡入時間。

## 片頭片尾卡內部專用

片頭（OP）、片尾（ED）的卡片由片頭／片尾樣式整段處理，卡片之間不是一般轉場：

| 寫法 | 用在哪 | 意思 |
| --- | --- | --- |
| `無切換` | OP、ED 除最後一張以外的卡 | 同一個畫面連續演出，由樣式自己處理 |
| `淡出至黑 1s` | ED 最後一張卡 | 全片最後 N 秒淡出到全黑 |

片頭最後一張卡用一般的 `黑場 a+bs`。

## 新增轉場時

1. 先走 `fx-lab` 做預覽、使用者拍板，以「已定案・待實作」寫進本檔，**標明是交疊型還是覆蓋型**。
2. 實作端三處一起改：`fx_notation.py` 的 `TRANSITIONS`；`render_storyboard.py` 的 `overlap_window()`／`overlap_render()`（交疊型）或 `overlay_tail()`／`overlay_head()`（覆蓋型）；`build_storyboard.py` 的 `validate()`（如有長度限制）。
3. 改完把狀態改成「已實作」。
