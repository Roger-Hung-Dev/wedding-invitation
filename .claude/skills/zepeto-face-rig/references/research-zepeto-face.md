# 研究：ZEPETO 臉的特徵，以及舊產線的頭為什麼不像（2026-10-13）

> 研究員（general-purpose 子代理）上網查參考、量我們三顆頭（新郎、新娘、攝影師；舊路線）後的報告整理。
> 參考圖存在 session 暫存資料夾（會被清掉），來源網址在文末。
> 這份報告促成了「新描述」與 AI 網格路線（[ai-mesh-route.md](ai-mesh-route.md)）。

## 結論

1. **差最多的是下半臉**：ZEPETO 是上寬下窄的 V 字臉、下巴小而尖；舊產線三顆頭的下巴、下顎寬了將近一倍（包子臉）。
   來源三個：生成描述寫 `soft rounded face`、Rodin 偏好圓胖公仔臉、包覆時把模板的窄下巴貼到 AI 頭的寬下巴上。
2. **第二是材質**：ZEPETO 皮膚光滑有亮澤、嘴唇有光、頭髮有反光（接近迪士尼 3D）；舊產線是霧面黏土（粗糙度 0.75、次表面散射 0.3），描述也寫 `matte clay`。
   → 使用者 2026-10-13 選「亮澤」。
3. **眼睛、嘴巴、鼻子形狀**：ZEPETO 杏仁眼＋雙眼皮線＋上揚眼線、嘴唇有厚度有唇峰、鼻子小但有鼻樑；舊產線眼睛太圓偏小太近（描述寫死 `large round`）、嘴是一條線、鼻子是一顆圓球。
4. 眼睛高低、整顆頭長寬比大致對，不用改。
5. **ZEPETO 官方做法**（Snow 2018 開發分享）：17 種基底臉按比例混合＋80 種五官部件＋10 種妝容＋51 種表情。
   像不像本人靠「固定的漂亮基底臉＋小範圍調整」，不是照照片重雕一顆頭。

## ZEPETO 臉特徵表

H＝頭頂（不含頭髮）到下巴的高度。從「預設光頭臉正面」（兒童預設）加格線量，誤差約 ±5%；成人臉的下半臉可能再長 5～10%。

| 部位 | 特徵 | 量化（約） |
| --- | --- | --- |
| 頭型 | 額頭頭頂很大，臉往下收成 V 字 | 高寬比 1.29；眼睛以上佔 60% |
| 下巴、下顎 | 下巴小而尖，下顎線清楚 | 下巴往上 5% 處全寬 0.28H、10% 處 0.39H、15% 處 0.45H；眼睛高度 0.75H |
| 眼睛位置 | 略低於頭高中線 | 下巴往上 40% |
| 眼睛大小、間距 | 大，兩眼間約一個眼寬 | 眼寬 29% 臉寬；兩眼中心距 56% 臉寬（成人 PRO 約 21%、51%） |
| 眼睛形狀 | 杏仁眼，上眼皮蓋住虹膜頂端，眼尾一筆上揚眼線，雙眼皮線，睫毛細而少 | 眼高 ÷ 眼寬 0.64；虹膜約 57% 眼寬 |
| 眉毛 | 細、淺棕、有毛流，離眼睛近 | 粗 2.6% H；眉心比眼睛高 10% H |
| 鼻子 | 小，有鼻樑亮面、圓鼻頭、鼻翼 | 寬 22% 臉寬；鼻尖在眼睛到下巴的正中間 |
| 嘴巴 | 窄，有唇峰，下唇較厚，有光澤 | 寬 36% 臉寬；唇厚 6% H；下唇線在下巴往上 9% H |
| 耳朵 | 中大、往外張 | 上緣約在眉毛高度 |
| 脖子 | 細長、幾乎是直筒 | 官方約頭寬的 33～34%（身體端從 Studio 官方預設身體正面量，截圖解析度低，實際 31～35%）。**產線目標 38%（容許 35～40%）**，見下方「2026-10-14 更正」 |
| 皮膚 | 光滑有亮澤，臉頰淡粉，新版有臥蠶、眼影 | 不是霧面 |
| 頭髮 | 一束一束髮片，有流向和亮面 | — |
| 頭身 | 頭和手刻意放大 | 官方約 4.4 頭身（光頭）≈ 4 頭身（含頭髮）；我們的身體採 4.5 頭身（含頭髮）。以身體端研究為準，見下方「2026-10-14 更正」 |
| 真人 → ZEPETO | 保留：髮型、髮色、膚色、臉型大方向、鬍子、眼睛類型。統一：眼睛放大、鼻子縮小、下巴收尖 | 「像本人但更漂亮」 |

### 2026-10-14 更正：頭身比、脖子（以身體端研究為準）

原本這張表寫「全身 5.5～6 頭身」「脖子寬約頭最寬處的 40%」，是從 App 預設臉的截圖推的，和身體端用 **ZEPETO Studio 官方預設身體**（creatorBaseSet，光頭、沒穿衣服、正視圖）量的結果對不上。兩份研究講同一組數字，以身體端為準：

- **頭身比**：官方約 4.4 頭身（光頭）≈ 4 頭身（含頭髮）。我們的身體採 **4.5 頭身**（含頭髮；身體端研究 https://claude.ai/artifact/JudBvPg4xRPimxfBwRZcwL ）。頭端不用為頭身比改頭的大小：身體照頭量尺寸長出來，頭就是量尺。
- **脖子**：官方脖子從下巴底下到肩膀幾乎是直筒，寬約光頭寬的 **33～34%**（頭寬 84 px、脖子 27～28 px；截圖解析度低，差 1 px 就差約 ±2%，實際 31～35%）。
- **產線目標 38%（容許 35～40%）**，不直接用 34%：我們 4.5 頭身、官方約 4 頭身，我們的頭對身體小約 11%（以「下巴到腳底」為單位，光頭寬 0.192 vs 官方 0.215），「佔頭寬幾 %」和「佔身體多寬」不能兩個都對上官方。
  - 換算成身體：新娘測試頭寬 0.202 m，脖子照 34% 做＝身體的 0.065（比官方 0.073 還細 11%，穿衣服像細頸）；照 **38%＝0.073，剛好等於官方脖子對身體的比例**；40%＝0.077 也可以。
  - 量法：頭寬＝Head 最寬處（不含頭髮、耳朵）；脖子寬＝接口環的左右寬（＝身體脖子頂端）。前後厚度跟著左右同比例縮（官方只有正面圖，量不到厚度）。
  - 2026-10-14 頭端、身體端對齊；產線的量測在 `scripts/zepeto_ratio.py`（`NECK_TARGET`），修細在 `rig` 步驟（見 ai-mesh-route.md「修細脖子」）。

## 當時建議的改法（後來怎麼處理）

| 建議 | 後來 |
| --- | --- |
| 包覆時下半臉不貼 AI 外型、下顎釘到 ZEPETO 比例 | 做成 `ZEPETO_CONTOUR`（V 臉）；AI 網格路線只拿來當籠子（見 ai-mesh-route.md 2.2） |
| 材質：粗糙度 0.45～0.5、次表面散射 0.1～0.15 | 採用（`gloss.py`：0.5／0.15；加 Coat 會泛白，不用）；2026-10-14 起後處理預設也是這組 |
| 眼睛：杏仁形、雙眼皮、上揚眼線 | AI 網格路線：AI 自己畫好；程式眼珠做成杏仁形 |
| 嘴唇厚度、唇峰 | AI 網格路線：AI 自己畫好 |
| **生成描述**：拿掉 `smooth matte clay`、`soft rounded face`、`large round`、`cute tiny nose`；改寫 almond eyes、V-line jaw、defined bridge、cupid's bow、glossy | 採用（新描述見 ai-mesh-route.md 第 1 節）；2026-10-14 已改進生成端子代理 `zepeto-analyze-photo-3d-model` |
