# 分鏡稿格式契約（storyboard/v2）

> **這份是雙方契約**：畫稿的一方照這裡命名與填寫，讀稿的一方（`extract_raw.js` → `build_storyboard.py`）照這裡解析。
> 名稱差一個字，解析器就找不到那一列 —— **不會報錯，只會少一筆資料**，所以命名一律照抄本檔。
> 特效的寫法不在本檔，在四份特效技術文件：[[fx-camera-motion]]、[[fx-transition]]、[[fx-title-opening]]、[[fx-title-ending]]。

## 1. 畫布分區

```
y=0   ┌ 00 總覽 ┐ ┌ 01 片頭字卡 ┐ ┌ 02 片尾字卡 ┐ ┌ 03 圖例與製作備註 ┐   ← 參考帶（左→右）
      └─────────┘ └────────────┘ └────────────┘ └──────────────────┘
      ┌ 10 分鏡列・片頭 ───────────────────┐
      ├ 11 分鏡列・第 1 章 {章名} ──────────┤                              ← 分鏡列（上→下＝時間順序）
      ├ 12 分鏡列・第 2 章 {章名} ──────────┤
      ├ …                                  ┤
      └ NN 分鏡列・片尾 ───────────────────┘   ← 編號最大的一列
```

| 頂層 frame 名稱（開頭固定） | 內容 | 解析器讀什麼 |
| --- | --- | --- |
| `00 總覽` | 片名、製作規格、時間軸、各章代表照 | `規格-*` 列 |
| `01 片頭字卡…` | 片頭 1:1 參考畫面＋`參數表-片頭` | `參數-*` 列 |
| `02 片尾字卡…` | 片尾 1:1 參考畫面＋`參數表-片尾` | `參數-*` 列 |
| `03 圖例與製作備註` | 運鏡／轉場圖例、版型說明、製作備註 | 不讀（給人看） |
| `10 分鏡列・片頭` | 片頭卡 | 鏡頭卡 |
| `11`～`1N 分鏡列・第 N 章 {章名}` | 章節標頭＋鏡頭卡 | 章節標頭、鏡頭卡 |
| `NN 分鏡列・片尾` | 片尾卡 | 鏡頭卡 |

- 分鏡列的名稱必須是「兩位數編號＋空格＋`分鏡列`」開頭。片頭固定 `10`，片尾的名稱要含「片尾」，且編號最大。
- 列內：章節標頭（寬 320）在最左，鏡頭卡（寬 480）由左到右＝時間順序。間距 20、內距 32。卡片之間不畫箭頭。
- 頂層 frame 樣式：`$bg-ivory` 底、1px `$border-soft` 框、圓角 16。
- `enabled:false`（隱藏）的節點解析器一律略過。參考線命名 `參考線-…（輸出前關閉）`。

## 2. 總覽的製作規格（必填）

在 `00 總覽` 裡放一個 `製作規格` frame，每一列：

```
frame 規格-{鍵}
├ text 標籤  "{給人看的名稱}"
└ text 值    "{值}"            ← 解析器只讀名為「值」的文字節點
```

| 鍵（列名 `規格-*`） | 必填 | 寫法 | 例 |
| --- | --- | --- | --- |
| `解析度` | ✅ | `寬×高` | `1920×1080` |
| `影格率` | ✅ | 數字 | `60` |
| `總長` | ✅ | `m:ss` | `4:00` |
| `配樂` | ✅ | 已剪好、長度＝總長的音檔絕對路徑 | `D:\婚禮籌備\婚紗輪播影片\產生器\music_240.wav` |
| `照片原檔` | ✅ | 原始照片目錄（產影片用原檔，不用稿上的縮小版） | `D:\婚禮籌備\婚紗照\全部毛片` |
| `字型目錄` | ✅ | 片頭片尾字型檔所在目錄 | `D:\婚禮籌備\婚紗輪播影片\fonts` |
| `底色` | ✅ | 模糊底壓暗色／分割縫／空白處底色 | `#1E2A33` |
| `CRF` | | H.264 畫質（越小越好，預設 16） | `16` |
| `位元率上限` | | 預設 `20M` | `20M` |

⛔ **影格率寫 60**。v1 稿寫「30 fps（建議）」是過期資訊（第 2 版已改 60fps）。

## 3. 章節標頭（每個章節列最左邊）

```
frame 章節標頭  寬 320  填章節色
├ text 章號       "Chapter 1"          Great Vibes 44
├ text 章名       "台中國漫館"          Noto Serif TC 30/700   ← 解析器讀這個當章名
├ text 英文副標   "TIMELESS"           18/600 字距 3
├ （60×1 分隔線）
└ frame 資訊-{鍵} × 7：時段／歌曲／情緒／鏡數／照片／調色／地點   每列 標籤＋值
```

- **`資訊-調色` 必填**，值是調色預設名（清單見 `storyboard-video-render` 的 `references/grading.md`）：
  - 整章一種：`暖褐復古`
  - 章內有區段：`明亮通透｜S2-06～S2-13：明亮通透・副歌`（多段用 `；` 分隔）
  - ⛔ 不能寫形容詞（「暖褐復古＋輕微底片顆粒」）。要新的調色就先新增預設。
- 片頭、片尾列沒有章節標頭也可以；有的話「地點」寫 `—`。

## 4. 鏡頭卡（v2）

```
frame 鏡-{鏡號}  480 寬  垂直排列  白底  1px $border-soft  圓角 8  clip
├ frame 畫面 16:9  480×270  absolute  底色＝規格底色  clip      ← 縮圖＝成片 1/4（§5）
│ └ frame 鏡號標籤  10,10  #00000080 圓角 10 └ text 鏡號
└ frame 標註  fill_container  垂直  gap 8  padding [12,14,14,14]
  ├ frame 鏡號列（space-between）
  │ ├ frame 左：text 鏡號（17/700 章節色）＋ text 時間碼（14/400 $text-muted）
  │ └ frame 秒數（章節色膠囊）：text 秒「3 秒」
  ├ text 畫面描述（14/700，只寫畫面內容）
  ├ frame 列-版型  ：text 標籤「版型」＋ text 值
  ├ frame 列-運鏡  ：text 標籤＋ icon（lucide 15px 章節色）＋ text 值
  ├ frame 列-轉場  ：text 標籤＋ icon ＋ text 值
  ├ frame 列-字卡  ：text 標籤＋ text 值
  └ frame 列-素材  ：text 標籤＋ text 值（$accent-gold）
```

| 欄 | 寫法 | 檢查 |
| --- | --- | --- |
| 鏡號 | 片頭 `OP-01`、正片 `S{章}-{兩位數}`、片尾 `ED-01` | 卡片名 `鏡-{鏡號}`、縮圖鏡號、標註鏡號三者相同 |
| 時間碼 | `m:ss–m:ss`（可用小數秒 `3:50.5`） | 全片首尾相接；`終點−起點`＝秒數膠囊 |
| 秒 | `{秒數} 秒` | — |
| 畫面描述 | 只寫**畫面裡有什麼**。⛔ 不寫時間行為（「自黑場 1.5 秒淡入」屬於上一鏡的轉場欄） | — |
| 版型 | 正片：`A 直式置中＋模糊底`／`H 橫式滿版`／`B 分割畫面`／`C 回顧格`（開頭字母必填）；片頭片尾：`片頭：{樣式}`／`片尾：{樣式}` | 照片張數：A／H 1 張、B 2 張、C 2～6 張 |
| 運鏡 | 照 [[fx-camera-motion]] 的「分鏡寫法」，**參數寫齊** | 版型與運鏡要相容 |
| 轉場 | 照 [[fx-transition]] 的「分鏡寫法」，寫的是**本鏡→下一鏡** | 黑場只用在章節交界 |
| 字卡 | 正片目前只支援 `—（無）` | 有字卡會被擋 |
| 素材 | 一行一張；B 版型用 `左：`／`右：` 開頭；可寫路徑，解析器只取檔名 | 檔名要在「規格-照片原檔」裡找得到 |

- 備註一律放在**全形括號**裡，解析器會整段忽略：`慢拉 115→100%（建立場景）`、`wedding-photo/1800px/dobe-5113.jpg（原規劃：格子門前）`。
- 圖示要跟詞彙一致：推移 `→` 用 `chevrons-right`、`←` 用 `chevrons-left`（v1 稿左推也用了右箭頭）。

## 5. 縮圖的畫法（480×270＝成片 1/4）

縮圖上的座標 ×4 就是成片像素；產影片時不讀縮圖，但人看稿是看縮圖，**縮圖畫錯，人就會核錯**。

| 版型 | 縮圖子節點 | 換算到 1920×1080 |
| --- | --- | --- |
| A 直式置中＋模糊底 | `模糊底圖` -20,-20 520×310（同張照片、blur 18）＋ `壓暗` 0,0 480×270（底色 40%）＋ `直式原圖` 150,0 180×270（fill） | 照片 720×1080 置中 |
| H 橫式滿版 | 一張 480×270 照片（fill） | 1920×1080 |
| B 分割畫面 | 左右各一組「模糊底＋壓暗＋直式原圖」，中間留一道細縫 | 左 0–959、右 961–1920，中縫 2px |
| C 回顧格（4 張） | 4 格 113×169.5，x 8／125／242／359，y 50.25 | 每格 452×678，x＝32＋468×i，y 201 |

- 直式原圖一律用 `fill`（v1 有 3 張用 `fit`，看起來會有細邊）。
- 放照片前先縮成長邊 1800px 的版本（原圖 3000 萬像素一次放幾十張，Pencil 會載不動、變棋盤格）。稿上用縮小版，產影片用「規格-照片原檔」的原檔，**兩邊檔名必須相同**。

## 6. 片頭片尾參數表

`01 片頭字卡` 放 `參數表-片頭`、`02 片尾字卡` 放 `參數表-片尾`。每列：

```
frame 參數-{參數路徑}      例：參數-title.size、參數-subtitles.lines.0.text
├ text 標籤  "{中文說明}"
└ text 值    "{值}"
```

每種樣式需要哪些參數路徑，見 [[fx-title-opening]]／[[fx-title-ending]] 該樣式的「參數表」。**缺參數產影片時會失敗**，請照該表逐列畫齊。

## 7. 自我檢查（畫完必做）

畫完不要只看截圖，跑一次解析器：

1. 用 `mcp__pencil-server__execute` 執行 `storyboard-video-render/scripts/extract_raw.js`（唯讀），把印出的整行 JSON **原樣**存成 `raw.json`。
2. `python .claude/skills/storyboard-video-render/scripts/build_storyboard.py raw.json -o storyboard.json`
3. 有錯就照錯誤訊息改稿，再跑一次，直到印出 `ok：N 鏡`。

錯誤訊息會指出鏡號與可用寫法，例：

```
[S1-04] 運鏡「慢推」不符合任何寫法；可用寫法：「慢推 100→108%／慢拉 115→100%／…」
```

## 8. v1 → v2 差異（舊稿要轉換時看）

| 項目 | v1（wedding-photo-slideshow.pen） | v2 |
| --- | --- | --- |
| 版型 | 沒有欄位，只能從縮圖反推 | 新增 `列-版型` |
| 運鏡／轉場參數 | 多數沒寫（「慢推」「溶接」） | 參數必寫（`慢推 100→108%`、`溶接 0.8s`） |
| 製作規格 | 只有給人看的規格卡 | `規格-*` 列，含配樂與原檔路徑 |
| 調色 | 形容詞 | 預設名＋區段 |
| 片頭片尾 | 散文＋規格表 | `參數-*` 參數表 |
| 影格率 | 30 fps | 60 fps |

完整 v2 標註範例（由第 2 版成片反推）見 [references/v2-sample.md](references/v2-sample.md)。
