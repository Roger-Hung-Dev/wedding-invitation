# 動作檢查

## 1. 量什麼

`check_lib.analyse(代號)`（`run_analyse` 會逐一呼叫）：

| 欄位 | 意思 | 門檻 |
| --- | --- | --- |
| `pen_core` | 手/前臂頂點穿進身體、頭的最深距離（mm） | ≤ 5 |
| `pen_hands` | 兩手互穿（mm） | ≤ 5 |
| `pen_legs` | 兩腿互穿（mm） | ≤ 5 |
| `foot_min` | 最低鞋底高度（cm），負的＝陷地 | ≥ −0.5 |
| `foot_float` | 「最低那隻腳」離地最高的一格（cm） | ≤ 0.5（jump／cheer／spin 這類騰空動作除外） |
| `vmax`、`jerk`、`seam` | 每格最大轉角、轉角變化、頭尾相接那格（度） | 以渲染時的 `motion.json` 為準（只算身體骨頭） |
| `slide_step` | 滑步：踩在地上的腳，鞋底每格的水平位移最大值（mm／格） | ≤ 1 |
| `slide_total` | 滑步：踩在地上的腳，整段（含頭尾相接那格）水平位移累計，左右腳取大的（mm） | ≤ 5 |

`motion.json`（`render_actions` 逐格量）：`body_vmax` ≤ 15°／格、`body_jerk` ≤ 6、`finger_vmax` 另計不擋。

### 滑步怎麼量（`check_lib.sole_world`／`slide_between`）

前面幾項量不到「腳在地上拖著走」：腳底高度一直是 0、轉速也很慢，但整隻腳在地板上左右平移。所以每格都量：

1. 取鞋底取樣點（和貼地用的是同一批：鞋子 rest 時 z < 1.2 cm 的頂點，用腳骨矩陣換算成世界座標）。離地 ≤ 5 mm 的點算「踩在地上」。
2. 相鄰兩格，每隻腳只取**兩格都踩在地上的同一批點**，算它們的平均水平位移。所以抬腳、墊腳尖、腳跟離地不會被當成滑動；騰空的腳不算。
3. 每格的最大值＝`slide_step`；每隻腳整段加總、取大的＝`slide_total`。

門檻的由來：動作預覽 400×600，全身約 520 px 高，1 px ≈ 3 mm。累計 5 mm 不到 2 px，看不出來；舊版的滑步動作累計 60～190 mm（20～60 px），一眼就看得出腳在滑。

⚠️ 有些動作設計上就會讓腳在地上動：`walk`（跑步機式原地走）、`turn`／`spin`（在原地轉，腳掌貼地旋轉）。這幾個會超標，屬於「已知、還沒改」，數字見 actions-catalog.md，不要拿它們當新動作的範本。

## 2. 量法的坑（都踩過）

1. **只用最近點的面法線判斷內外會誤判**：細長的手指在邊角會被當成「在裡面」。改用平滑頂點法線，並用一條往外的短射線交叉確認（要從裡面穿出表面才算）。
2. **最近點落在網格切口邊緣（手腕、前臂分組邊界）時不計**，否則會量到 49 mm 這種比手掌還厚的假穿模。
3. **超過 20 mm 的「穿入」視為誤判**（最近點在背面）。
4. 若一批動作的穿模都卡在 19.x mm（剛好在上限下），那是真的穿模，要找 `Checker.worst_at` 給的點去拍近照。
5. **`pen_core` 不量手對大腿**：網格分組時大腿屬於「腿」組，`core` 只有軀幹和頭。手貼大腿的姿勢（立正、男性鞠躬手貼褲縫）就算手插進大腿，`pen_core` 也是 0。這類姿勢要拍近照，必要時用 `Checker.groups` 的 `legL`／`legR` 面另外量手對大腿的距離（2026-10-05 男性鞠躬就是這樣量的：最近 5～7 mm、穿入 0）。
6. 手指交握、手搭在短褲上、拍手掌心互碰 —— 量到 5～20 mm 是正常接觸，皮膚在衣服底下或手指本來就會疊。**要目視確認**，然後在 `actions_catalog.json` 的 `contact_note` 寫原因，網頁才會標成「接觸」而不是「穿模」。

## 3. 修法對照

| 症狀 | 常見原因 | 修法 |
| --- | --- | --- |
| 某一格速度暴衝（30～90°） | `palms` 接近 180° 翻面 | 改 `twist` 固定角度 |
| 某一格速度突變（jerk 大） | IK 目標超出手臂長度，伸直後手肘一格彎回 | 目標點收近（離肩膀 < 0.4 m） |
| 手指尖速度高 | 手勢切換太快（招手） | 減少開合次數或幅度；手指不擋 |
| 雙腿互穿（蹲） | 膝蓋往內 | 大腿先繞 Z 往外開（`L: Z +`、`R: Z −`） |
| 腳陷地 / 浮空 | 手動設了 root z | 拿掉 root z，交給 `ground=True` |
| 腳在地上滑（`slide_*` 超標） | 用 `root` 平移重心、`Hips` 側傾／扭轉、`legs()` 的腿角度：腿是 FK，骨盆一動腳就被帶走；`ground` 只修高度、不修水平位置 | 姿勢加 `feet=PLANT`（`pose_lib.plant_feet`：腿 IK 把腳踝鎖在地上），骨盆照樣用 `root` 的 x／y 移、z 給負值＝膝蓋彎；要換腳位就抬腳（`feet` 的 lift > 0）移過去再放下，水平移動只放在腳離地之後（`a_dance` 的 `_step`） |
| 鎖腳後腳還是滑一點、膝蓋突然打直 | 骨盆離腳太遠，腿伸直也構不到 | 骨盆多降一點（root z 更負），或骨盆側移時另一腳先抬起 |
| 兩手合握的穿模隨上身擺動忽大忽小 | 手臂是世界軸 FK，上身一旋轉，左右手相對姿勢就變 | 上身側擺改成「骨盆側傾、腰椎反向轉回同樣角度」（只平移不旋轉），或改用 IK |
| 手壓在頭上、穿臉 | 目標點太靠近 | 改 IK，指尖目標離皮膚 1～3 cm |
