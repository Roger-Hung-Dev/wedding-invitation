# 姿勢慣例

## 1. 座標與角度

- 角色面向 **−Y**，角色的左手邊是 **+X**，上是 +Z。單位公尺。
- `rot_world(arm, 骨頭, 軸, 角度)`：在**骨架空間（世界軸）**繞骨頭頭部轉。同一根骨頭的多個旋轉依序套用。
- `apply_pose` 先 `reset_pose`，再依 `BODY_ORDER`（父骨先）逐根轉；手指在 rest 狀態先轉（結果是相對父骨的局部旋轉，會跟著手臂走，並且快取）。

| 想要的動作 | 寫法 |
| --- | --- |
| 左手垂下／右手垂下 | `L_UpperArm: Y +72`／`R_UpperArm: Y −72`（90 是貼身，72 是自然垂手） |
| 手臂往前抬 | 垂下之後 `X −角度`（左右同號） |
| 手臂往上舉過頭 | `L_UpperArm: Y −55～−60`／`R: Y +55～+60` |
| 前臂往前彎（手肘） | `L_LowerArm: X −角度`；往身體中線收 `L: Z −`、`R: Z +` |
| 前臂往上（揮手） | `R_LowerArm: Y +`、`L_LowerArm: Y −` |
| 低頭／抬頭 | `Head: X +`（低頭）／`X −` |
| 轉頭向左／右 | `Head: Z +`（轉向 +X＝角色左邊）／`Z −` |
| 歪頭 | `Head: Y +`（往角色左邊倒） |
| 彎腰往前 | `Spine: X +`；側彎 `Spine: Y` |
| 大腿往前抬 | `UpperLeg: X −`；小腿往後彎 `LowerLeg: X +` |
| 膝蓋往外開（大腿已水平時） | `L_UpperLeg: Z +`、`R_UpperLeg: Z −`（要放在 X 之前） |

⚠️ 鏡頭若斜 20～30°，「往前伸」的手在畫面上看起來像往旁邊伸，判斷姿勢對不對要量骨頭方向，不要只看小圖。

## 2. 姿勢 dict 的其他鍵

| 鍵 | 例 | 說明 |
| --- | --- | --- |
| `hands` | `("relax", "open")`、`("relax", ("open", "grip", u))` | 左右手勢；三元組＝兩種手勢內插（u 0→1） |
| `ik` | `[("R", 手腕, 手肘方向點, 指尖方向點)]` | 世界座標。手腕精準到點；第 4 個可省略（手掌順著前臂，避免翻面） |
| `twist` | `[("R", 91)]` | 繞前臂軸固定轉幾度（前臂、手腕各一半）。掌心要轉 >120° 一律用這個 |
| `palms` | `[("R", (0,-1,0), w)]` | 自動轉到掌心朝某方向；w 0~1 淡入。只適合角度 < 120° 且手臂不經過和目標平行的狀態 |
| `root` | `(x, y, z)` | 整體位移 |
| `rz` | `180` | 整體繞 Z 轉（度），轉身／轉圈 |
| `ground` | `True`（預設） | 整體上下平移讓最低的鞋底貼地（鞋底取樣點 × 骨頭矩陣，不算網格，很快） |
| `hop` | `0.2` | 貼地之後再往上抬（跳躍） |
| `feet` | 見 actions.py 的 `PLANT` | 腳底鎖定（腿部 IK）：腳踝釘在地上固定位置，骨盆可自由移、膝蓋自動彎。重心移動、彎腰、扭腰的動作一律要寫，否則腳會跟著骨盆在地上滑。要換腳位就抬腳、移過去、再放下（例：`dance` 的 `_step`） |
| `face` | `{"Fcl_ALL_Joy": 1}` | 表情 shape key（見 library-defaults.md） |
| `no_stand_fix` | `True` | 不套男性站姿統一層（`pose_lib.stand_fix`，2026-10-08）。預設對男性角色、有 `feet` 或自動貼地的姿勢：骨盆往後轉 11°、腰椎轉回 12.5°（不前傾）；鎖腳的站姿骨盆基本下沉從 3 mm 收到 0.8 mm（膝蓋約 175°）；骨盆低 3～6 cm 漸漸不套（蹲、坐）。手的 IK 跟著 Hips 走、骨盆一轉手會偏的動作要寫這個（例：`taste`）；原地轉身 `turn`／`spin` 也排除。全域關掉：`STAND_FIX = False` |

`pose_frame` 的順序：姿勢 → 位移/旋轉 → 貼地 → IK → twist → palms → 表情。⚠️ 貼地一定在 IK 之前，否則 IK 對好的手會被整體平移帶走。

## 3. 體型縮放

所有寫死的座標（IK 目標、道具位置）都是**新娘量的**。`actions.py` 提供：

- `BODY_S = 頭骨高度 / 1.386`
- `bs(x, y, z)` → 乘上 `BODY_S` 的 Vector

新動作的 IK 座標一律用 `bs(...)` 包。腿的角度用 `legs(P, 下降公尺)`（依該角色的腿長算，不必縮放）。

## 4. 速度

- 擺姿勢時先 `mesh_eval(False)`：關掉網格的骨架變形（只影響視窗評估，渲染不受影響），否則每轉一根骨頭就重算整個網格，一個姿勢從 0.5 秒變好幾秒。
- `rot_world` 不在結尾 update（下一次開頭會做）；讀骨頭矩陣前自己 `bpy.context.view_layer.update()`。
- `bpy.ops.render.render` 每格約 0.6～1 秒（400×600、16 samples）。

## 5. 頭髮與裙擺物理

- 頭髮：VRM add-on 的 spring bone（只留名稱含 hair 的 spring），每格 2 個子步驟 `SB.update_pose_bone_rotations(ctx, 1/48)`。先空跑半輪讓頭髮穩定再開始存影格。
- 裙擺：`skirt_phys.py` 的 `Skirt_Sway` 骨頭（腰固定、下擺慢半拍、跳起時拉長、落地時張開、`extra_flare` 讓轉圈撐開）。
- ⚠️ 物理迴圈裡 `pose_frame` 會 reset 所有骨頭（包括頭髮），所以要在**最後一個子步驟之後**直接渲染，不要再呼叫一次 pose_frame。
