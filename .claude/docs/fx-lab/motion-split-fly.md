## 使用者原始描述
> 新郎由上往下飛入，新娘由下往上飛入，速度幫我挑適合的

（用在婚紗輪播 S2-04：B 分割畫面，左格新郎、右格新娘。）

| 使用時機 | 新郎／新娘單人照對照；章內偶爾一次的亮點 |
| 已知坑 | 第一格位移約 147px（30fps）；不可 snap；前一鏡不要接推移、黑場；溶接 ≤ 0.6s；人物偏上緣時方向可對調 |

## 分鏡寫法的解析（給實作端）

建議正規式（加進 `fx_notation.py` 的 `MOTIONS`）：

```
^分割上下飛入\s*左\s*(↓|↑)\s*右\s*(↓|↑)\s*{NUM}\s*s\s*延遲\s*{NUM}\s*s\s*微推\s*{NUM}\s*→\s*{NUM}\s*%$
```

`↓`→`"down"`、`↑`→`"up"`。`MOTION_LAYOUTS` 加 `"split-fly": {"B"}`。開頭詞「分割上下飛入」不與「分割一推一拉」「分割右格晚進」衝突。

## 與產生器的差距
- 產生器沒有動態模糊，起飛前幾格位移大，可能有一點跳；預覽時若覺得跳，先把時長拉到 0.8s。
- 實作要改 `render_shot()` 的 B 分支：格子先合成好再整格位移，不能沿用 `place_center(..., snap=...)` 的靜止對齊。
