## 0. 共通規則（10 版都照這裡）

### 0.1 成片與字級（以 1920×1080 計）

| 項目 | 規則 |
| --- | --- |
| 大標 | ≥ 140px（名字、數字、單字標語）。倒數數字 600～700px |
| 字幕主句 | ≥ 72px，本稿建議 **84px**（像素字型版用 88px，見 V03） |
| 標籤 | 徽章上的短字（≤ 6 字，例「溫馨提醒」）72px，不算字幕行 |
| 同時字數 | 同一時間字幕主句**最多 2 行**、每行 **≤ 16 個中文字**；大標另計，同時最多 2 個 |
| 停留時間 | 每句停留 ≥ 字數 ÷ 6 秒，且 ≥ 2.5 秒；2 行同時出現時以兩行字數合計；標點也算一個字 |
| 英數字 | 半形英文、數字以 2 個算 1 個中文字（例「Happiness Loading...」19 個半形字≈10 個中文字寬） |
| 安全框 | 文字一律落在 90% 安全框內（左右 96、上下 54） |

### 0.2 版面分區（避開字幕）

- **字幕區**：畫面中央 x 360～1560。2 行 84px 字幕最寬 16×84＝1344px。
- **角色欄**：角色站在左右兩側欄（左下／右下為主），全身高 45%～60%（寬約為高的 0.35 倍，約 170～230px），不進字幕區。
- 角色要走到中下時（推進度條、推列車），那段時間字幕放在畫面上半部。

### 0.3 字幕欄寫法

- 一句一行，用 `<br>` 分行，順序＝出現順序。
- `／`＝同一句拆成兩行**同時**出現（算 2 行）。
- 句尾的全形括號 `（起～訖s）`＝本鏡內的顯示時間（從本鏡開頭算）；這是**給人看的註記，不上畫面**。
- 畫面上真的要顯示的括號一律拿掉或改成副句樣式，避免和「全形括號＝註記」混淆。
- `【大標】`、`【標籤】` 是字級標記，不上畫面。

### 0.4 角色列寫法（照 storyboard-pen-format §4.1）

- `{角色}｜{動作}｜{位置}｜{大小}｜{起}～{訖}s｜{選填}`，一行一段，兩人就分行。沒有角色寫 `—（無）`。
- 同一角色在同一鏡可以有多行（依序做不同動作）。
- **時間窗比動作長時，動作做完接 idle（站姿待機）直到訖**；動作長度見動作庫（例：bow 3 秒、wave 2 秒）。
- 道具（香檳杯、相機、麥克風）寫在動作後的全形括號裡；帽子、徽章等「造型配件」用 2D 貼圖疊上，寫在素材欄。
- 服裝一律預設禮服：新娘粉色歐根紗蓬裙禮服、新郎米色三件式西裝＋深藍領結。

### 0.5 轉場與時間

- 轉場欄照 fx-transition 的寫法（`硬切`／`溶接 Ns`／`推移 ← Ns`／`閃白 0.08+0.22s 85%`／`黑場 a+bs`／`淡出至黑 1s`）。主題味道寫在全形括號裡；括號裡寫「建議 fx-lab 設計」的，是現有特效庫沒有、要另外做的效果。
- 黑場只用一次：⑦→⑧（注意事項講完、燈暗準備倒數），當作段落交界。
- 每版 8 鏡、時間碼首尾相接，整數秒。最後一鏡一律 `淡出至黑 1s`，接現場燈光與新人進場音樂。
- 鏡號 `V{版本}-{鏡}`，例 `V03-05`。
