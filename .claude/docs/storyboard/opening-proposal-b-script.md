## 換順序後的定案（2026-10-12 使用者採用建議）

1. **B3 的地點：走廊上的代客泊車指示立牌。** 原本的「門口泊車牌」不用，因為 B3 現在在路線中段，「門口」只留給 B6。
2. **B2 → B3 語意相連**：先「吃到飽、喝到醉」，接著「喝酒不開車」。
3. **B5 → B6**：拍照背板擺在宴會廳門口，自拍完一轉身就到大門。
4. **遮擋換景的兩個接縫**：
   - B3 → B4：柱子從鏡頭前掃過（餐飲區 → 攝影區）。
   - B5 → B6：門框遮擋，進入大門前的最後一段。
   - 其餘用側面跟拍連續捲動：B0 → B1 → B2 → B3、B4 → B5。
   - 所以製作上分成三段場景：① B0～B3（休息室 → 走廊 → 餐飲區）② B4～B5（攝影區）③ B6（大門）。每段可以分開做、分開修。
5. **B1 之後的下一站是餐檯（B2）。** B1 第 4 版的動作不用改，只有走掉時從右邊先捲進來的道具，要從攝影師換成餐檯。
