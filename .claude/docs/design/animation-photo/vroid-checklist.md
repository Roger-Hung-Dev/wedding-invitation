# VRoid 捏臉清單：新郎、新娘

> 依據同資料夾的照片：`新郎-大頭照.jpg`／`新郎-正面.jpg`／`新郎-背面.jpg`、`新娘-大頭照.jpg`／`新娘-正面.jpg`／`新娘-背面.jpg`，以及婚紗照 `wedding-photo/dobe-5308.jpg`。
> 用途：在 VRoid Studio 捏出開場影片要用的 3D 角色，匯出 VRM 後交給 Blender 做動畫（測試流程見「拉載入條」測試片）。
> 滑桿的確切名稱依 VRoid 版本可能不同，下面寫的是「要調哪一類、往哪個方向」。

## 第一次用 VRoid：一步一步操作

> 按鍵與畫面位置取自 VRoid 官方說明（v2 版）。中文介面的按鈕名稱可能和這裡寫的略有不同，括號內附英文原名方便對照。

### 1. 安裝、切成中文

1. 到官網 <https://vroid.com/studio> 按下載（選 Windows），或在 Steam 搜尋「VRoid Studio」安裝，都免費。
2. 打開後如果是英文或日文介面，到設定（齒輪圖示）裡找「語言（Language）」，選繁體中文。找不到中文就用英文，下面都有附英文名稱。

### 2. 建立角色

1. 首頁左邊按「新建（Create New）」。
2. 選基礎模型：**新郎選「男性（Male）」，新娘選「女性（Female）」**。建議先做新郎，短髮比較好上手。

### 3. 認識畫面

| 位置 | 是什麼 | 怎麼用 |
| --- | --- | --- |
| 上方一排分頁 | 臉部（Face）、髮型（Hairstyle）、身體（Body）、服裝（Outfit）、飾品（Accessories） | 點分頁切換；也可以按鍵盤 F1～F5 |
| 左邊一排圖示 | **最上面那個是「預設集」**，下面是各部位（例如眉毛、眼睛、鼻子、嘴巴、耳朵） | 點部位圖示，右邊就會出現那個部位的設定 |
| 右邊 | 滑桿 | 左右拖曳調整大小、位置、角度 |
| 中間 | 3D 角色 | **按住滑鼠右鍵拖曳＝轉動角色**；Shift＋左鍵拖曳＝移動畫面；Ctrl＋`;` 放大、Ctrl＋`-` 縮小 |
| 數字鍵 | 快速切換視角 | **1＝正面**、**3＝右斜前方**（對照照片最好用） |

- 改壞了：**Ctrl＋Z** 復原，Ctrl＋Shift＋Z 重做。
- 存檔：**Ctrl＋S**。

### 4. 捏臉（臉部分頁，F1）

1. 左邊**最上面的圖示（預設集）**，先挑一張最接近的臉：
   - 新郎：挑眼睛比較細長、臉比較長的。
   - 新娘：挑眼睛中等偏大、臉比較柔和的。
2. 依序點左邊的部位，照下方「新郎／新娘」表格的說明拖右邊的滑桿：**臉型 → 眼睛 → 眉毛 → 鼻子 → 嘴巴 → 耳朵**。
3. 每調完一個部位，按 **1** 看正面、按 **3** 看斜側，跟照片比對。
4. 不知道哪條滑桿是什麼，就左右拖一下看角色哪裡在變。拖壞了按 Ctrl＋Z。

### 5. 髮型（髮型分頁，F2）

1. 左邊**最上面的圖示（預設集）**挑最接近的髮型：
   - 新郎：短髮、瀏海往前蓋住額頭的。
   - 新娘：中分的長髮。
2. 把髮色改成黑色（或黑中帶深棕）。
3. **第一次先不要編輯單一髮束**，那是 VRoid 最難的部分。預設集挑得接近就好，卡住了截圖給 Claude。
4. 新娘的蝴蝶結不用在這裡做，Claude 會在 Blender 加。

### 6. 身體（身體分頁，F3）

- 只調**身高**：新郎比新娘高 12～15 公分。其他滑桿維持預設即可。

### 7. 服裝（服裝分頁，F4）

- 新郎：最簡單的襯衫＋長褲；新娘：貼身的簡單衣服。顏色不拘，禮服和西裝 Claude 會在 Blender 做（見下方「服裝怎麼辦」）。

### 8. 存檔

- 按 **Ctrl＋S**，存成 `groom.vroid`、`bride.vroid`，放在這個資料夾（`animation-photo`）。

### 9. 匯出 VRM（給 Claude 用）

1. 按右上角的匯出圖示，選「**匯出 VRM（Export VRM）**」（或按鍵盤 **F8**）。
2. 匯出頁面上的減面設定**不用動**，直接按「匯出（Export）」。
3. 格式選 **VRM1.0**。
4. 必填兩欄：**Avatar name**（新郎填 `groom`、新娘填 `bride`）、**creator**（填你的名字）。其他欄位可以空著。
5. 按「匯出（export）」，存成 `groom.vrm`／`bride.vrm`，放在這個資料夾。

### 卡關怎麼辦

按 **Win＋Shift＋S** 截取 VRoid 畫面，直接貼給 Claude，說明「哪裡不像」或「找不到哪個按鈕」。

## 開始之前

1. 新增角色時，**新郎選預設的男性模型、新娘選女性模型**，再從最接近的預設臉型開始改，比從零開始快。
2. 每改完一大項就 **存檔（.vroid）**，檔名建議 `groom.vroid`／`bride.vroid`。
3. 兩人要分開捏、分開存，最後各匯出一個 VRM。
4. 捏的時候開「正面」和「側面」兩個角度對照照片，只看正面很容易把臉捏太扁。

## 新郎

| 部位 | 照片特徵 | VRoid 要怎麼調 |
| --- | --- | --- |
| 臉型 | 偏長的鵝蛋臉，顴骨略寬，下巴窄、略尖，下顎線清楚 | 臉拉長一點；下巴往下延伸、收窄；臉頰不要鼓 |
| 眼睛 | 細長的杏仁眼，眼尾微微上揚，內雙或很淺的雙眼皮 | **眼睛整體縮小、上下高度壓低**（預設眼睛對他來說太大太圓）；眼尾往上一點；瞳孔深棕色；睫毛調短、調淡 |
| 眉毛 | 平直、偏粗，眉尾微揚，眉毛離眼睛近 | 眉毛加粗、拉平；位置往下靠近眼睛 |
| 鼻子 | 鼻翼略寬、鼻頭圓 | 鼻子比預設稍大，鼻頭圓一點 |
| 嘴巴 | 中等寬度、嘴唇薄，平常閉嘴淺笑 | 嘴唇調薄；嘴角微微上揚 |
| 耳朵 | 明顯外張 | 耳朵調大一點、往外張 |
| 膚色 | 自然、偏暖 | 預設膚色往暖色調一點 |
| 髮型 | 黑色短髮；頭頂蓬鬆有層次；**瀏海往前垂，蓋住額頭上半**，髮尾一撮一撮不整齊；兩側和後腦剪短、露出耳朵 | 從預設男生短髮改：頭頂髮束加蓬；瀏海髮束往前、往下垂到額頭一半；兩側和後腦髮束剪短；髮色黑中帶一點深棕光澤 |
| 身材 | 偏瘦；比新娘高約 12～15 公分（婚紗照裡新娘頭頂大約在新郎嘴巴高度） | 身高比新娘高 12～15 公分；身形偏瘦 |
| 服裝 | 米色三件式西裝：單排扣外套、背心（4 顆深色扣子）、白襯衫、**深藍斜紋領結**、米色西褲；鞋子照片看不到，用棕色皮鞋 | VRoid 內建沒有三件式西裝，見下方「服裝怎麼辦」 |

## 新娘

| 部位 | 照片特徵 | VRoid 要怎麼調 |
| --- | --- | --- |
| 臉型 | 鵝蛋臉，臉頰柔和；2D 版定案是「圓臉再瘦一點、下巴微尖」 | 臉頰柔和不凹；下巴微尖但不要太長 |
| 眼睛 | 中等偏大的杏眼，雙眼皮，眼尾自然 | 眼睛中等偏大；雙眼皮明顯；瞳孔深棕色；保留睫毛 |
| 眉毛 | 平順自然，細到中等粗 | 眉毛拉平、細一點 |
| 鼻子 | 小巧 | 維持預設或再小一點 |
| 嘴巴 | 自然的玫瑰粉唇色，微笑 | 唇色調玫瑰粉；嘴角微微上揚 |
| 髮型 | 黑長髮、**中分**；**半紮髮**：上半部往後梳綁起，臉旁留兩縷細髮；下半部是到背中段的**大波浪捲髮** | 從預設長髮改：中分；上半部髮束往後收；臉旁加兩縷細髮；下半部髮束加長到背中段、加捲度 |
| 髮飾 | 後腦一個**粉色、半透明紗質的大蝴蝶結** | 配件新增蝴蝶結，放後腦正中、尺寸大一點、顏色淡粉 |
| 耳環 | 花瓣造型加珍珠的垂墜耳環 | 配件新增耳環：金色小花瓣加一顆珍珠垂墜 |
| 身材 | 纖細 | 身高比新郎矮 12～15 公分 |
| 服裝 | **粉色平口曳地蓬裙**：領口一道反摺、腰帶加偏左的蝴蝶結、腰側大片荷葉層（右大左小）、外層半透明紗；裙底露出**白色球鞋** | VRoid 內建沒有這種禮服，見下方「服裝怎麼辦」 |

## 服裝怎麼辦（已定案：在 Blender 做）

**VRoid 裡只捏臉、頭髮、身材，衣服交給 Claude 在 Blender 做**（2026-10-04 試做定案：新娘禮服效果好；新郎西裝全身鏡頭可用，特寫略有瑕疵）。

在 VRoid 裡請這樣選衣服：

- **新郎**：最簡單的襯衫＋長褲（顏色不拘）。
- **新娘**：最簡單、貼身的連身裙或上衣＋短褲（不要蓬裙，Blender 會蓋一件曳地蓬裙上去）。
- **不要讓角色光著匯出**：VRoid 匯出時會刪掉衣服底下看不到的皮膚，Blender 的衣服是以這層底衣為基礎做的。
- 鞋子：新郎選皮鞋、新娘選白色球鞋，VRoid 有就直接選；沒有的話之後在 Blender 換顏色。

萬一新郎西裝的特寫不滿意，備案是到 BOOTH 找現成的 VRoid 西裝素材（搜尋「VRoid スーツ」）。

## 捏完之後

1. 在 VRoid 選「匯出 VRM」，版本選 **VRM 1.0**。
2. 匯出時會要你填作者、授權等資料，作者填自己名字即可，授權選「僅限本人使用」。
3. 檔名用 `groom.vrm`、`bride.vrm`，放在這個資料夾，跟 Claude 說一聲，就會匯入 Blender 換掉測試角色。
