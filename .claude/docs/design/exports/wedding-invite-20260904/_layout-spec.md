# 版面規格數值：wedding-invite-20260904

**用途**：這是給前端代理**精確對位**用的數值，直接照抄即可，**不用再目測圖片比例**。
數值取自 Pencil 的 `Get`／`ctx.bounds` 實測，單位一律 px。

**設計稿基準寬度**：
- **裝置版（手機）：390**（Hero 段為 390x844）
- **電腦版：1440**

**指路**：**視覺長相看同目錄 `_index.md` 的圖，兩份搭配使用** —— 這裡只有數字，沒有長相。

## 讀這份文件前要知道的三件事

1. **間距是用 spacer frame 實作的，不是 flex gap。** 設計檔裡是 `spacer-20`、`sp-48` 這種空 frame，
   所以我把它記在「與下一元素間距」欄。**下游寫 CSS 時用 `margin` 或 `gap` 都可以**，不必照著塞空 div。
2. **⚠️ `ctx.bounds` 已知有系統性偏移**：本檔出現的 y 座標**只能拿來做相對比對**，
   絕對定位請以各段自身的 padding 與元素高度重算。
3. **色票寫成 `$變數名`**（如 `$primary`、`$accent-gold`、`$text-muted`、`$text-invert`、`$text-invert-muted`），
   實際色碼請查分析檔第 9.1 節，本檔不重複。
