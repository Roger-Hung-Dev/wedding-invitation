「好久不見，我們婚禮見」放置比稿　20 式

照網站由上往下排：開場層 → 封面 → 婚禮邀請函 → 段落之間 → 各段落 → 頁尾與分享。每一格都是手機畫面，用網站實際的配色、字型與婚紗照。有「動態」標籤的，這一頁上就會動給你看。

兩個版本的文案怎麼選：「好久不見，我們婚禮見」多了「我們」，讀起來像新人親口在說，適合橫排的一行字；「好久不見，婚禮見」少兩個字、節奏更俐落，直排或放大字級時比較好排（例如 03、06、11）。同一個網站可以兩種並用：主要的位置用長句，直排與跑馬燈用短句。

首選　10 照片淡出＋一行字跟你第一張參考圖同一種做法，插在兩段之間當「呼吸」，不動到任何現有區塊，情緒最到位。
次選　17 See You There 的中文副標交通區的英文主標剛好就是「到時見」，中文放在正下方像翻譯又像問候，改動只有一行字。
也很適合　01 開場弧形標題賓客點開連結第一眼就看到，比「婚禮邀請函」四個字更有溫度；同樣只換一行字。
