# 需要標註作者的素材

素材庫裡用了 **CC BY** 授權的外部素材時，在這裡加一列。
影片片尾，或喜帖網站的致謝區，要照「標註文字」欄列出來。

- CC0 和自己建的道具不用列。
- 來源網站的資料在 `sources.md`。
- 每樣素材的來源也寫在 `catalog.json` 的 `source`。
