## 5. track.json 怎麼用

```json
{ "1": { "letter_text_area": [[x, y, 深度], [x, y, 深度], [x, y, 深度], [x, y, 深度]] }, "2": { … } }
```

- 鍵是影格編號（字串，從 1 起算，對應同資料夾 `beauty\0001.png`）。
- 每個區域 4 個點：**左上、右上、右下、左下**，成片像素（原點在左上角）；第 3 個數字是相機深度（>0 才在鏡頭前，桌面幕都 >0）。
- 用法：把要寫的字排在「區域的正面矩形」裡，再用 4 點做透視（或近似成平移＋旋轉＋縮放，桌面幕都是正上方俯拍，透視很小）。鏡頭在慢推，所以每格都要套。
- 區域清單：①`letter_text_area`；④`groom_name_border`、`bride_name_border`、`groom_photo`、`bride_photo`；⑥`postcard_right_half`、`phone_screen`。
